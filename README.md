# Chat UI (Frontend Only)

Modern, responsive social media–style chat application UI (WhatsApp / Telegram–inspired).

## Tech
- HTML5
- CSS3 (Flexbox + Grid)
- Vanilla JavaScript
- Frontend only (mock data)

## Run
Open chat-ui/index.html directly in your browser.

## GitHub Pages
If you enable GitHub Pages (Settings → Pages) for the main branch root, the repo root index.html will redirect to /chat-ui automatically.

## Project structure
- `chat-ui/index.html`
- `chat-ui/style.css`
- `chat-ui/script.js`
- `chat-ui/assets/avatars/`
