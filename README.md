# Chat UI (Frontend Only)

Modern, responsive social media–style chat application UI (WhatsApp / Telegram–inspired).

## Tech
- HTML5
- CSS3 (Flexbox + Grid)
- Vanilla JavaScript
- Frontend only (mock data)

## Run
Option A (recommended):
- From the repo root, run: `python -m http.server 5173`
- Open: http://localhost:5173/chat-ui/

Option B:
- Open `chat-ui/index.html` directly in your browser.

## Project structure
- `chat-ui/index.html`
- `chat-ui/style.css`
- `chat-ui/script.js`
- `chat-ui/assets/avatars/`
